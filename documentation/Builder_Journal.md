## Why Did I Choose Computer Vision?

I chose Computer Vision because it combines Artificial Intelligence with visual information from the real world. Images and videos contain a large amount of information, and I am interested in developing systems that can automatically analyze this information and support practical applications.

Computer Vision also provides a strong foundation for advanced areas such as object detection, tracking, segmentation, and intelligent video analytics.

## What Did I Learn This Week?

During Week 1, I learned the fundamentals of digital images and practical image processing. I worked with pixels, resolution, RGB and grayscale images, color channels, and common image formats.

I also learned how to use OpenCV for:

* Image loading and processing
* Grayscale conversion
* Gaussian and Median filtering
* Canny edge detection
* Thresholding
* Drawing shapes and text
* Image transformations

I used NumPy for image-array operations, Matplotlib for histogram visualization, and Streamlit to create the Vision Toolkit web interface.

I also practiced Git and GitHub for version control and project documentation.

## Biggest Challenge

The biggest challenge was integrating different computer vision operations into a single interactive application. I also faced issues with Python packages, module imports, and webcam functionality while developing the application.

## How Did I Solve It?

I solved these problems by testing individual components, checking error messages carefully, organizing the project structure, and using the appropriate Streamlit camera interface instead of relying on a local OpenCV camera window.

I also tested image-processing operations individually before integrating them into the application.
